# Consulta de voos

Aplicativo Flutter que consulta voos por código ICAO e permite selecionar chegadas, partidas ou todos os registros.

## Personalizações desta versão

- Campo de aeroporto com teclado em maiúsculas e envio pela tecla de pesquisa.
- Cards de voo e tela de detalhes com apresentação visual ajustada.
- Liberação do controlador de texto ao fechar a tela.

**Adaptação:** João Pedro Cardoso. Esta pasta contém personalizações sobre o código-base recebido; mantenha os créditos do material original conforme a orientação da atividade.

## Como executar

Rode `flutter pub get` na pasta deste projeto e inicie a API Python antes de executar o app. O endereço da API está configurado em `lib/services/voo_service.dart`.
